# ダンスアニメーション素材

2026年10月7日、内蔵 image_gen.imagegen で生成。4キャラクターの透明PNGを参照し、同じキャラクターの連続する8ポーズを描いた。単一の静止画を移動・回転して作った素材ではない。画像生成後、同じ内蔵ツールで格内の余白を広げる修正を行った。PNG の手動切り抜き、Python/Pillow などによる画像編集はしていない。

## ファイルと読み込み

- shark_dance.png
- cat_dance.png
- worker_dance.png
- chicken_dance.png

全て 1774 × 887 ピクセル、実際のアルファ透過、4列 × 2行。フレーム番号は上段の左から 0, 1, 2, 3、下段の左から 4, 5, 6, 7。

セルサイズは Vector2(443.5, 443.5)。この小数値を保って source region を計算する。整数へ早く丸めると末尾の列に誤差が出る。セルごとに別の倍率へ正規化せず、各キャラクター内で共通の描画サイズを使用する。10〜12fps 程度のループを起点に調整する。

## 見た目の確認

- サメ：3本の脚・3足の青白いスニーカーを保持。前脚・中脚・後脚が順番に上がり、尾と胸びれの向き、しゃがむ深さが変わる。
- 猫：同じ灰白の主猫。前足を上げる、左右へ出す、しゃがむ、跳ぶ、着地するなどが連続する。
- 会社員：同じ青い服・黒髪・茶色い鞄。片膝を上げる、腕を横へ伸ばす、鞄を振る、しゃがむ、両足を揃えて跳ぶ。
- ひよこ：同じ黄色い体・黒いセンター分け・灰色サロペット。片足を上げ、翼を胸へ寄せ、横へ開き、しゃがみ、両翼を上げて跳ぶ。ボールなし。

## QA

四枚とも画像として確認し、各セルの画像データのハッシュは8種類あった。ハッシュの違いだけで動作を判定せず、手足と身体の形が変わっていることも目視で確認した。

| ファイル | 完全透明ピクセル数 | 各セルの端16px内にある alpha > 192 のピクセル |
| --- | ---: | --- |
| cat_dance.png | 1,152,565 | 全8セルとも0 |
| chicken_dance.png | 1,249,243 | 全8セルとも0 |
| shark_dance.png | 1,195,836 | 全8セルとも0 |
| worker_dance.png | 1,145,461 | 全8セルとも0 |

主体の輪郭は隣のセルに越えていない。薄いアルファの細かい生成ノイズが一部残る場合があるため、不要ならゲーム側で低アルファを除外できる。ひよこに一度生成された薄い区切り線は内蔵画像編集で除去した。

下段の通常ポーズの足位置は上段よりわずかに高く配置されている。7→0のループ位置を揃えるには、フレーム4〜7へ固定の下向き描画補正を加えることを推奨する。補正はフレームごとの拡大縮小ではなく、下段全体の固定位置修正。フレーム5の跳躍そのものは保持する。

| キャラクター | 下段だけ加える元画像座標の y 補正 |
| --- | ---: |
| shark | +38px |
| cat | +40px |
| worker | +48px |
| chicken | +22px |

ゲーム内の値は上の数値 × 描画セルの高さ ÷ 443.5。
