# 幻想夜市ステージ

2026年10月7日更新。stage.png は「ねこマート幻想夜市」の新しい対戦背景。内蔵 image_gen.imagegen を使用し、ユーザーの明るい浮島・桜・床照明の参考画像をもとに、オリジナルの日本風夜市を生成した。参考画像のキャラクター、牛、HUD、メニュー、ロゴ、中国語は使っていない。

## 画風とゲーム内配置

原寸1659 × 948、不透明PNG。1792 × 1024 と同じ1.75の横長比率。ゲームの1280 × 720へ全画面描画すると、比率差は小さい。出力PNGは画像編集やリサイズをせず、原寸のままプロジェクトへコピーした。

全体は明るい青紫の夜空、桃色の桜、遠景の鳥居・浮島・瀑布、中景の猫ネオンの便利店・屋台、手前の桃金色に照らされた石板。写真のアスファルトや粗いピクセル描写を避け、描かれた輪郭と色面で統一している。

石板の後ろ端は画像高さの約70.5%。画像高さの82%、つまり720pxのゲームで y=590 は、全幅にわたって開いた石板の上にある。ここには段差、茂み、売店、柵、別の物体を置いていない。接触影と足元のエフェクトはゲーム側で描画する。

人物照明は、上部に淡い青紫、足元・前面に暖かい桃金色が合う。背景に人物・戦闘エフェクト・血条・タイマー・画面UIは含まれない。空にある小さい顔付き気球は環境装飾。

## 保存と確認

現行の画像は assets/art/stage.png。旧来の写実寄りの夜の便利店背景は work/art-backups/stage-night-convenience-v1.png にコピーして保存した。

生成された画像を実際に表示して、空のステージであること、石板が平坦であること、y=82%の足元線が石板に接すること、人物を隠す前景がないこと、招牌が「ねこマート」であることを確認した。ファイルの寸法と不透明も検証済み。

stage-fantasy-generation.json に完全な提示文、参照画像のパス、ネイティブ生成画像のパスを保存した。generation-prompts.json の stage エントリーは、旧便利店背景の生成記録として保持している。
